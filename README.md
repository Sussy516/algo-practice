# algo-practice

Daily algorithms, data structures, and system design primitives in Python with automated `unittest` coverage.

## Run Tests
```bash
python3 -m unittest discover -s tests -v
```

## Track Progress
```bash
python3 scripts/stats.py
```

## Topics Covered
- **Arrays & Hashing:** Two Sum, Maximum Subarray (Kadane), Merge Intervals
- **Strings & Stacks:** Valid Parentheses
- **Searching:** Binary Search & Lower Bound
- **Dynamic Programming:** Climbing Stairs
- **Design:** O(1) LRU Cache
- **Graphs:** BFS Shortest Path in Grid
